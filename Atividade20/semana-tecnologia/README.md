# Atividade 20 — Semana de Tecnologia

Projeto solicitado na Atividade 20, utilizando Node.js, Express, EJS e módulos de rotas.

## Como executar

1. Abra o terminal dentro da pasta do projeto.
2. Execute:
   npm install
3. Depois execute:
   npm start
4. Acesse:
   http://localhost:3000

## Rotas

- `/` — Página inicial
- `/sobre` — Informações sobre o evento
- `/programacao` — Programação
- `/contato` — Contato
- `/admin/inscricao` — Formulário de inscrição

O projeto segue a estrutura solicitada, com o servidor em `app/config/server.js`, views em `app/views` e rotas separadas em `app/routes`.
